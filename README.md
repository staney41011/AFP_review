# AFP / CFP 考前快速複習

依 115 年考輔講義整理的快速複習網頁。

## 內容

- NM1～NM7 七科核心重點
- 必背公式與法規數字
- 易錯觀念整理
- 20 題隨機快速測驗
- 「已掌握」進度紀錄（localStorage）
- 手機 / 電腦響應式版面
- 關鍵字快速搜尋

## GitHub Pages

如果尚未開啟 Pages：

1. 進入 Repo 的 **Settings**
2. 點 **Pages**
3. `Build and deployment` 選 **Deploy from a branch**
4. Branch 選 `main`，資料夾選 `/ (root)`
5. 按 Save，等待 GitHub 部署

預期網址：

`https://staney41011.github.io/AFP_review/`

## 更新方式

主網頁集中在 `index.html`。之後要補題目、修正法規數字、加入錯題本或新增計算工具，只需要更新這個檔案即可。
